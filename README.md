
# TA-IND-01 — Sistemas Distribuidos

## Descripción
Este proyecto tiene como finalidad analizar el funcionamiento de NATS JetStream como sistema distribuido y compararlo con Apache Pulsar.

Se estudiarán su arquitectura, comunicación, consistencia y tolerancia a fallos, aplicando los conceptos de la Unidad 1 mediante investigación y pruebas prácticas.
